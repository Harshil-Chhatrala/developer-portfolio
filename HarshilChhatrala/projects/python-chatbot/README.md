# Python Product Recommendation Chatbot

An interactive Python chatbot project that uses a laptop catalogue and helper logic to respond to user queries and provide product-related recommendations.

## Tech Stack
Python, CSV, application logic.

## Run
```bash
python -m venv .venv
# Activate the environment, then run:
python app.py
```

Review the imports at the top of `app.py` and install any missing dependencies in your virtual environment. Do not commit user-specific conversation logs or private data.
