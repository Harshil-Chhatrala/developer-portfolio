# MyGit — Git-Inspired Version Control System

A Python implementation exploring the core ideas behind a version-control tool.

## What to explore
- Command-line entry point in `main.py`
- Command implementations in `mygit/commands.py`
- Object storage and object handling in `mygit/objects.py`
- Index/staging support in `mygit/index.py`
- Reference handling in `mygit/refs.py`

## Tech Stack
Python, command-line programming, file handling, hashing, and data serialization.

## Run
```bash
python main.py
```

Check the command-line options and usage in `main.py` before running commands. Use a disposable test directory for experiments.

## Note
The original local `.mygit` repository metadata and Python cache files were intentionally excluded. This repository contains the implementation source, not a pre-populated test repository.
